# Security Policy

## Supported versions

Security fixes are provided for the latest released major version. Before the
first stable release, the `develop` branch is the supported preview line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/diffpal/diffpal/security/advisories/new)
to share a description, reproduction steps, impact, and any suggested fix.

We aim to acknowledge reports within three business days and will coordinate
disclosure and remediation with the reporter. Please allow a reasonable period
for a fix before public disclosure.

## Scope

Reports about DiffPal's CLI, provider execution, host integrations, release
artifacts, or credential handling are in scope. Provider CLIs and hosting
services maintained by third parties should be reported to their maintainers.
